# Regras do Projeto (AGENTS.md)

- **Git Push**: NUNCA execute o comando `git push` automaticamente. O agente deve realizar o `git add` e `git commit` quando solicitado, mas o `git push` para o repositório remoto será SEMPRE executado manualmente pelo usuário.
- **Idioma**: Toda a comunicação, código, documentação e respostas devem ser sempre em português do Brasil (pt-BR).
